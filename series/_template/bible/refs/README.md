# Reference images

Approved model sheets, turnarounds, expression sheets and location
establishing shots. These are canon: the identity and palette checks
compare every generated frame against them.

- Name files with versions: `aria/model_sheet_v003.png`
- Keep each image under ~3 MB (PNG or WebP). The repo whitelists
  `series/*/bible/refs/**` images in `.gitignore`; all other media
  stays out of git.
- Only images you generated with cleared models or drew yourself.
  Never add screenshots or art from existing anime.
